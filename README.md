Job Market Intelligence and Skill Gap Analyser

📌 Project Overview

The Job Market Intelligence and Skill Gap Analyser is a Python-based web application developed using Streamlit. It helps students and job seekers understand current job market requirements, explore in-demand skills, compare salaries, and identify skill gaps.

The application provides career insights and helps users prepare for industry requirements.

🎯 Objectives

- Analyse job market trends.
- Identify in-demand technical skills.
- Explore salary distributions across job roles and locations.
- Analyse resumes and identify missing skills.
- Compare different job roles.
- Provide learning roadmaps and portfolio project ideas.
- Help students prepare for career opportunities.

🚀 Features

- Job market overview and analytics.
- Job search and filtering.
- In-demand skills analysis.
- Salary comparison charts.
- Location-based job analysis.
- Resume upload and skill gap analysis.
- Job role comparison.
- Personalised learning roadmaps.
- Top 5 portfolio project ideas for different roles.
- External job search links.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/job-market-intelligence-skill-gap-analyzer.git

2. Open the project folder

cd job-market-intelligence-skill-gap-analyzer

3. Install dependencies

pip install -r requirements.txt

4. Run the application

streamlit run app.py

📊 Dataset

The project includes a sample dataset containing 150 job records with job titles, locations, salary information, and required skills.

Note: The sample dataset is intended for project demonstration and does not represent verified live vacancies or official salary information.

🎓 Expected Outcome

The application helps students understand job market expectations, identify missing skills, and plan their learning journey to become job-ready.
